      8×8
      1. Fülle jedes Feld mit einem X oder einem O.

      Spielregeln & Bedienung

      1. Schwärze (streiche) Felder, sodass in jeder Zeile und jeder Spalte keine Zahl mehr als einmal sichtbar bleibt.
      2. Geschwärzte Felder dürfen sich nicht seitlich berühren – diagonal ist erlaubt.

      4. Antippen/Klicken wechselt: leer → geschwärzt → sichtbar markiert (Kreis) → leer. Mit den Pfeiltasten bewegst du den Fokus; Taste S schwärzt, O markiert, Entf leert.

      Rätsel teilen

      Über „Teilen“ bei einem Rätsel in der Liste entsteht ein Link. Wer ihn öffnet, bekommt dasselbe Rätsel – ohne deinen Fortschritt. Einen erhaltenen Link oder Code kannst du hier einfügen.

      Gut zu wissen

      • Ein Rätsel erscheint hier, sobald du darin etwas eingetragen hast.
      • Dein Fortschritt wird automatisch gespeichert, auch wenn du ein neues Rätsel erzeugst.
      • Es werden die letzten 60 Rätsel behalten. Mit Konto ist der Verlauf auf allen Geräten verfügbar.

      Druckverlauf 0

      Anleitung zum Überdrucken vorbereiteter Blätter

      1. Drucken Sie zuerst Blatt 1 (Arbeitsblatt) als Vorlage auf Papier aus.
      2. Legen Sie das bedruckte Blatt passgenau (gleiche Oberkante) wieder in das Papierfach Ihres Druckers ein.
      3. Wählen Sie im Druckdialog zwingend „Tatsächliche Größe“ (100 % Skalierung) ohne „An Seite anpassen“, damit die Lösung exakt in die Felder gedruckt wird.
      4. Nutzen Sie die Blatt-1-Hilfslinien im Vorschaufenster zur visuellen Lagekontrolle — diese Hilfslinien werden nicht mitgedruckt.
